Firebase Security Rules đang chặn — Cần mở quyền đọc/ghi!
Nguyên nhân: Firebase mặc định từ chối tất cả truy cập. Bạn cần vào console Firebase để thay đổi Rules:
1. Vào Firebase Console → Realtime Database → Rules
2. Thay toàn bộ nội dung Rules bằng đoạn sau rồi nhấn Publish:
{ "rules": { ".read": true, ".write": true } }
3. Sau khi Publish, tải lại trang này — sẽ kết nối được ngay.
